# 01: Establish the Caffeine application shell

**What to build:** A Persian RTL dashboard shell with Caffeine light, dark, and system modes; a visible theme control; persistent `موقعیت تحویل`; and labeled responsive navigation that does not obstruct content.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Users can select light, dark, or system appearance, and their selection persists without a visible incorrect-theme flash.
- [ ] The shell uses Caffeine semantic tokens in both modes and preserves Persian typography, RTL reading order, visible focus, and responsive navigation.
- [ ] The active `موقعیت تحویل` is visible and reachable on desktop and mobile without covering dashboard content.
